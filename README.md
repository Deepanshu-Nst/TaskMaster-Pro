# ✨ TaskMaster Pro - Modern Todo List Application

A beautiful, feature-rich task management application built with React.js that helps you stay organized and productive. With a stunning modern UI, smooth animations, and powerful productivity features, TaskMaster Pro transforms the way you manage your daily tasks.

![TaskMaster Pro](https://img.shields.io/badge/React-19.0.0-61DAFB?logo=react)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?logo=javascript)
![Vite](https://img.shields.io/badge/Vite-6.2.0-646CFF?logo=vite)

## 🚀 Tech Stack

- **Frontend Framework:** React.js 19.0.0
- **Language:** JavaScript (ES6+)
- **Build Tool:** Vite 6.2.0
- **Storage:** Browser Local Storage (DOM API)
- **Styling:** CSS3 with Modern Features (Gradients, Animations, Glassmorphism)

## ✨ Features

### Core Functionality
- ✅ **Add Tasks** - Create new tasks with title, description, deadline, and priority
- ✅ **Edit Tasks** - Update task details inline with a beautiful edit form
- ✅ **Delete Tasks** - Remove tasks with smooth animations
- ✅ **Mark as Complete** - Toggle task completion with celebration animations
- ✅ **Search & Filter** - Search tasks by title/description and filter by status (All/Active/Completed)
- ✅ **Persistent Storage** - All tasks automatically saved to browser local storage

### Advanced Features
- 🌙 **Dark Mode** - Toggle between light and dark themes with persistent preference
- 🎯 **Priority Levels** - Assign High, Medium, or Low priority with color-coded badges
- 📅 **Smart Deadlines** - Visual indicators for overdue, due today, urgent, and upcoming tasks
- 📊 **Statistics Dashboard** - Real-time tracking of total, active, completed tasks, and progress percentage
- 🎨 **Modern UI** - Beautiful gradient backgrounds, glassmorphism effects, and smooth animations
- 📱 **Responsive Design** - Fully responsive layout that works on mobile, tablet, and desktop
- 🎉 **Celebration Animations** - Animated confetti when completing tasks
- 🎭 **Smooth Transitions** - Elegant animations for all interactions
- 🔍 **Advanced Search** - Search through task titles and descriptions
- 📋 **Task Sorting** - Automatic sorting by completion status, priority, and deadline

### UI/UX Highlights
- **Gradient Backgrounds** - Beautiful purple-to-pink gradients with animated overlays
- **Glassmorphism Cards** - Modern frosted glass effect on task cards
- **Hover Effects** - Interactive hover animations on all clickable elements
- **Custom Checkboxes** - Styled checkboxes with smooth transitions
- **Empty States** - Helpful messages when no tasks are found

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone <your-repository-url>
   cd my-do-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```

## 📖 Usage

1. **Add a Task**: Click the "➕ Add New Task" button and fill in the details
2. **Set Priority**: Choose High, Medium, or Low priority when creating/editing tasks
3. **Set Deadline**: Add a deadline date to get visual reminders
4. **Complete Tasks**: Click the checkbox to mark tasks as complete
5. **Edit Tasks**: Click the edit button (✏️) to modify task details
6. **Delete Tasks**: Click the delete button (🗑️) to remove tasks
7. **Search**: Use the search bar to find specific tasks
8. **Filter**: Use the filter tabs to view All, Active, or Completed tasks
9. **Toggle Theme**: Click the theme toggle button (🌙/☀️) to switch between light and dark mode

## 💾 Data Persistence

All task data is automatically saved to the browser's local storage, ensuring:
- Tasks persist across browser sessions
- No data loss on page refresh
- Theme preference is remembered
- Works offline (no server required)
